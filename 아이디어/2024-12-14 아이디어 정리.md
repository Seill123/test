					- 채팅에서 칭찬을 받음
					- 피드에서 좋아요와 팔로우를 많이 받음
					- 신고 내역 적음
			- 스토리
				- 사용자 사진 테두리 색깔 변경
					- 스토리는 보라색, 활동 중 초록색, 확인 후 회색

		- **사용자 국가(위치 정보 수집 인증)**
			- 위치 검증 후 표시
				- 해당 현 위치 정보가 설정 나라와 일치하는지
		- **사용자 자기소개**
			- 사용자 한줄 소개
		- **포인트**
			- 사용자가 채팅에서 칭잔을 받음

			- 구메 후 포인트 상품가격 0.1%
		- **설정한 학습 언어**
		- **피드 개수**
		- **팔로워**
			- 사용자가 팔로워 한 사람 목록 표시
		- **팔로우**
			- 사용자를 팔로우 하는 사람 목록 표시
		- **프로필 공유**
			- 카카오톡 공유
			- 링크 공유
			- 채팅 공유
		-  **내가 작성한 피드 표시** 
		- **목록**
			- 나의 거래
				- 구매 내역 페이지
					- 구매한 티켓
					- 구매한 선물
				- 선물 받은 내역 페이지
					- 사용 완료
						- 후기 작성 버튼 열림 (후기 작성 가능)
					- 사용 가능
				- 위시리스트
					- 선물 구매 페이지에서 내가 찜한 선물
				- 내가 작성한 후기(이용한 날짜 지난 후 작성 가능)
					- 작성 완료한 후기를 모아 볼 수 있음 (후기 목록)
					- 후기 삭제 및 수정
			- 고객 지원

				- 문의 하기

# 공급자 웹사이트

    - **상품 목록 보기**
        - 등록된 상품의 상태(판매 중, 일시 중단) 표시
        - 검색 및 필터 기능(카테고리, 판매 상태 등)
    - **상품 삭제**

    - **예약 요청 확인**
        - 사용자 예약 요청 세부 정보 보기(날짜, 옵션, 인원 등)

    - **예약 현황 관리**
        - 예약 상태별 필터링(확정, 대기, 취소 등)
        - 날짜별 예약 통계 확인

    - 상품별 사용자 후기 보기
    - 부적절한 후기 신고 및 삭제 요청
- ### 결제 및 정산 관리

        - 월별 정산 금액, 수수료 확인
        - 정산 요청 및 상태 확인
    - **환불 관리**
        - 환불 요청 내역 확인 및 처리
- ### 문의 관리
    - 사용자가 남긴 문의 확인 및 답변
    - 문의 유형별 필터링(결제, 예약, 상품 등)
- ### 통계 및 리포트
    - 상품별 판매 통계
    - 인기 상품 순위 확인
    - 예약 및 취소 내역 통계
- ### 프로필 및 계정 관리
    - 사업자 정보 수정
    - 계정 비밀번호 변경
    - 다국어 지원 설정

## 관리자 웹사이트
- ### 대시보드
    - 시스템 현황 (사용자 수, 예약 현황, 피드 활동 등)
    - 주요 알림 (신고된 사용자, 상품, 문의사항 등)
    - 통계 분석 (사용자 활동, 거래 현황, 인기 여행지 등)
- ### 사용자 계정 관리
	- 전체 사용자 목록
		- 사용자 목록 조회, 검색, 필터링
    - 사용자 프로필 관리
	    - 사용자 정보 수정, 상태 변경 (활성/비활성)
    - 검증된 사용자 관리
	    - 인증된 사용자에 대한 확인 및 관리 (뱃지기능, 언어 능숙도 확인 등)
    - 사용자 신고 관리
	    - 신고된 사용자 목록, 신고 사유 확인 및 처리 (경고, 차단, 밴 처리 등)
    - 차단 및 매칭 시스템 관리
	    - 차단된 사용자 목록 및 복원 기능
- ### 피드 및 콘텐츠 관리
    - 피드/스토리 관리
	    - 피드 및 스토리 콘텐츠 검토, 삭제, 수정
	    - 특정 피드 및 스토리 검색
    - 댓글 및 좋아요 관리
	    - 댓글 및 좋아요 활동 모니터링, 댓글 삭제
    - 피드 신고 관리
	    - 신고된 피드 및 댓글 처리
    - 키워드 및 해시태그 관리
	    - 유해 키워드 필터링, 해시태그 관리
- ### 상품 및 예약 관리
    - 상품 관리
	    - 카테고리별 상품 목록 관리
	    - 한 공급자별 상품 목록 관리
	    - 나라별 상품 목록 관리
	    - 각 목록 마다 상품 검색 기능
		    - 상품 이름
		    - 공급자 이름
		    - 날짜
    - 카테고리 관리
	    - 상품 카테고리 관리 (숙소, 입장권, 투어 등)
    - 가격 및 할인 관리
	    - 가격 변경, 할인 설정
		    - 중고거래와 같은 개인 판매 사업은 공급자가 가격 조정을 하지만, 규모가 커질 경우 관리자에서 관리하고 공급자가 관리자에게 신하는 로직이 대부분이라고 함. (법적사항, 정책 등으로 인한 이유가 대부분)
    - 티켓 예약 관리
	    - 예약 현황 확인, 취소, 환불 처리
		    - 이 부분도 **공급자와 고객 간의 분쟁을 예방**하고, **공정한 환불 정책**을 유지하기 위해서 라고 함. (법적사항, 정책 등으로 인한 이유가 대부분)
    - 선물하기 관리
	    - 선물된 상품 관리
		    - 수량, 상품명, 공유한 유저 변경 등==(티켓만)

	    - 챗봇 설정, 자동 응답 관리
- ### 광고 및 프로모션 관리(선택하면 광고 상세 페이지)
    - 광고 게시물 관리
	    - 광고 게시물 등록, 수정, 삭제
    - 특가 상품 관리
	    - 특가 상품 등록 및 관리
    - 광고 피드 관리

    - 리워드 및 포인트 사용 내역(포인트, 리워드 어떤 부분에서 받는지)
	    - 사용자별 리워드 및 포인트 사용 현황
- ### 시스템 설정(관리자도 번역 필요)

    - 보안 관리

    - 데이터 백업 및 복원

    - **차단 목록 관리**: 차단된 사용자 관리, 해제 기능

    - 사용자 분석
	    - 신규 사용자 등록 현황, 활동 분석

    - 피드 및 커뮤니티 분석

    - 언어 학습 분석
