# 구매

## 1. 카테고리
- 숙소(부가 서비스)
- 입장권(예: 박물관)
- 투어(가이드, 패키지 투어)
- 액티비티(이용권)
- 교통편(교통 패스)

## 2. 추가 콘텐츠
- 광고 포스터 
- 목록
	- 인기 여행지
	- 특가 상품

## 3. 주요 기능
- 티켓 및 숙소 예약
	- 다양한 티켓 구매 가능(여행, 액티비티, 교통패스)
	- 다국적 결제 시스템
	- 금액 표시 및 선택 가능

- 숙소 공유(부가 서비스)
- 선물하기(티켓 공유)
- 환불 및 취소
- 포인트(리워드) 사용
- 할인 혜택

- 장바구니
	- 선택한 상품을 결제 창으로 이동
	- 추가 및 삭제 가능
	- 개수 선택

## 4. 상품 상세 페이지
- 상세 정보 제공
	- 찜한 수, 카테고리, 제목
	- 별점 리뷰(평균), 구매 건수, 리뷰 수
	- 위치 정보 및 찜하기 기능
	- 대표 사진과 상세 설명

- 옵션 선택 팝업
	- 패키지 구성 선택
	- 이용 기간
		- 기간 별 가격 차이 명시
	- 인원 선택
		- 성인,어린이 기준 가격 차이 명시

- 장바니 담기
	- 담긴  옵션의 간편 정보 표시
	- 체크박스로 선택 및 헤제 가능
	- 옵션 제거 / 전체 선택 및 해제 가능
	- 결제 상세 내역 확인

- 바로 예약하기 및 선물하기
	- 옵션  및 예약 정보 표시
	- 제목, 옵션, 날짜, 인원, 금액
	- 예약자 연락처 입력
	- 이름, 성, 전화번호, 이메일
	- 할인 및 포인트 사용 가능
	- 약관 동의 후 결제
	
- 선물하기
	- 받는  유저 검색 및 확인
	- 선물 정보 입력
	- 제목, 옵션, 날짜, 인원, 금액
	- 약관 동의 후 결제

## 5. 추가 정보 및 기능
- 후기 목록
	- 필터링 가능
		- 날짜 / 사진 포함 후기만
	- 후기 내용
		- 별점, 작성자, 날짜 포함
	- 자주 묻는 질문
		- 상품  관련 FAQ 제공
	- 문의 기능
		- 공급자에게 직접 문의 가능
		- 고객센터 페이지로 이동
	- 추천 상품
		- 추천  액티티 및 추천 티켓 표시

## 6. 결제 및 티켓 전송
- 이메일 전송
	- 티켓은 저장된 이메일로 자동 전송
	- 또는 결제 과정에서 이메일 입력 가능
- 결제 완료 후 티켓 전송
	- 고객에게 전송된 이메일로 티켓 및 구매 정보 확인 가능


# 문의

## 1. 문의 페이지 주요 기능
- 자주 묻는 질문(FAQ)
	- 고객센터에서 제공하는 FAQ 리스트
	- 사용자가 자주 질문하는 사항에 대한 간단한 답변 제공
- 문의 작성
	- 사용자가 새 문의를 작성할 수 있는 양식 제공
		- 제목
		- 내용
		- 첨부 파일(선택 사항)
	- 문의 작성 후 관리자 및 공급자에게 전달
- 문의 내역 및 내용 보기
	- 작성된 문의 및 답변을 확인 가능
	- 구조
		- 답변 : 화면 상단에 표시(관리자 / 공급자 응답)
		- 질문 사항 : 화면 하단에 표시(사용자가 작성한 내용)
	- 답변 상태 : 대기 중, 답변 완료 등 상태 확인
- 챗봇
	- 실시간으로 간단한 문의 처리 가능
	- 기본적인 FAQ 외 추가 정보 제공

## 2. 문의 확인 프로세스
- 관리자 확인
	- 고객센터 관리자 전용 확인 기능
	- 고객 문의에 대한 답변 및 관리 가능
- 공급자 확인
	- 상품 공급자가 확인 답변 가능한 문의 구분
	- 공급자와 관리자 역할 분리
