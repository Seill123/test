- 관리자 권한 로그인/ 회원가입
	- 현 관리자가 추가 관리자에게 코드 직접 전달
	- 현 관리자가 코드 생성 버튼을 누르면 코드 전용 데이터 테이블에서 코드 저장 및 전송
	- 전송된걸 받은 추가 관리자는 회원가입시 입력 후 코드 일치를 코드 전용 데이터 테이블에서 select 확인

	- 사용자 신고 내역 수리
	- 사용자 등록 검토 느낌으로 관리
	- 사용자 전체 나열 / 검색 / 필터링
	- 사용자 매칭 시스템 관리
	- 사용자 탈퇴 사유 및 수리
