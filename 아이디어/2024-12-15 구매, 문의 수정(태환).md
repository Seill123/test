## 장바구니(수정)
	- 장바구니에 담긴 상품들 목록
		- 간편 정보 표시
	- 선택한 상품을 결제 창으로 이동
	- 옵션 선택 가능
	- 전체 금액 표시 및 선택된 상품 금액 표시
	- 전체(개수) 선택 후 구매, 삭제 가능

	- 고객에게 전송된 이메일로 티켓 및 구매 정보 확인 가능
- 구매 내역에서 구매한 티켓 정보 확인 가능

# 문의(공급자로 다이텍트 문의할건지 관리자 거칠건지 정해야함)
	- 자주 묻는 질문(FAQ)
		- 고객센터에서 제공하는 FAQ 리스트
		- 사용자가 자주 질문하는 사항에 대한 간단한 답변 제공
	- 문의 작성
		- 사용자가 새 문의를 작성할 수 있는 양식 제공
			- 제목
			- (추가) 유형 - 예약 변경, 환불 등등
			- 내용
			- 첨부 파일(선택 사항)
		- 문의 작성 후 관리자 및 공급자에게 전달
	- 문의 내역 및 내용 보기
		- 작성된 문의 및 답변을 확인 가능
		- 구조
			- 답변 : 화면 상단에 표시(관리자 / 공급자 응답)
			- 질문 사항 : 화면 하단에 표시(사용자가 작성한 내용)
		- 답변 상태 : 대기 중, 답변 완료 등 상태 확인
		- (추가) 답변 완료 시 앱 내 알림 또는 이메일 발송
	- 챗봇
		- 실시간으로 간단한 문의 처리 가능
		- 기본적인 FAQ 외 추가 정보 제공
